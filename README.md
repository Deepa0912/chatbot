# chatbot

# 🤖 ChatBot AI — Intelligent Assistant

A AI-powered chatbot web application built with **Flask** and **GitHub Models (GPT-4o)**, featuring voice input/output, a sleek dark UI, and deployment on **Render**.

---

## ✨ Features

- 💬 **Real-time AI Chat** — Powered by OpenAI GPT-4o via GitHub Models API
- 🎤 **Voice Input** — Speak your questions using the browser's Speech Recognition API
- 🔊 **Voice Output** — Hear AI responses with text-to-speech synthesis
- 📝 **Markdown Rendering** — Supports bold, code blocks, lists, and more
- 💡 **Suggestion Cards** — Quick-start prompts on the welcome screen
- 🗑️ **Clear Chat** — Reset conversation history with one click
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile
- ✨ **Premium Dark UI** — Glassmorphism, gradient accents, and smooth animations
